Ohuhu

Local Storage jest niedostępny w tym sposobie otwarcia strony, więc zmiany nie zostaną zapamiętane po zamknięciu. Zapisz kopię w zakładce „Dane”.
Aplikacja się nie uruchomiła. Ta strona potrzebuje JavaScriptu. Podgląd pliku w iOS (aplikacja Pliki, załącznik w poczcie lub komunikatorze) go nie uruchamia, więc dane się nie pokazują. Otwórz stronę w Safari z adresu https://.

Kopia i przenoszenie danych

Katalog zestawów i Twoje zaznaczenia są zapisywane w Local Storage tej przeglądarki. Żeby przenieść je na inne urządzenie, zapisz plik JSON i zaimportuj go tam.

Import

Format pliku

{
  "sets": [
    {
      "id": "honolulu-72",
      "name": "Honolulu 72",
      "label": "72",
      "series": "Honolulu",
      "colors": [
        { "code": "KOD", "name": "Nazwa", "hex": "#RRGGBB" },
        "KOD; Nazwa; #RRGGBB"
      ]
    }
  ],
  "owned": ["honolulu-72"],
  "singles": [
    { "series": "Oahu", "code": "KOD", "hex": "#RRGGBB" }
  ]
}

Kolor można podać jako obiekt albo jako tekst „kod; nazwa; #hex”. Pola „owned” i „singles” są opcjonalne, hex w „singles” też.

Wbudowany katalog

Przywraca wbudowane zestawy Honolulu i Oahu (np. jeśli któryś usunąłeś albo zmieniłeś). Twoje własne zestawy i zaznaczenia zostają.

Reset

Usuwa własne zestawy, pojedyncze kolory i zaznaczenia, przywraca stan początkowy.
